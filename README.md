# AutoSmokeGuard — Frontend

React web client for the AutoSmokeGuard vehicle smoke detection and emission-report system, developed as a university Final Year Project.

## Tech Stack

- **React** + **Vite** – Modern React tooling with fast HMR
- **Redux Toolkit** – State management
- **React Router** – Client-side routing
- **Tailwind CSS** – Utility-first styling

## Structure

- `src/` – Application source code
- `ui_mockups/` – Reference design mockups and wireframes

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Sprint Scope

- **Sprint 1** – Repository foundation (this commit)
- **Sprint 2** – Tailwind CSS UI shell and layout components
- **Sprint 3** – Authentication UI (login/register screens)
- **Later sprints** – Dashboard, reports, vehicle management, real-time alerts
